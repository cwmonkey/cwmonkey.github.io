Usage and description

This script adds a dimmer button to youtube videos.

Install the Greasemonkey script below to bypass the Twiter API call (which seems to break fairly often). This also ends up being faster than the Twitter API in displaying embedded Tweets. This will also embed tweets when domains like xcancel.com are used.
